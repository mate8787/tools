📊 Video Link Analyzer

Paste links below and fetch video stats — copy the table straight into Excel.

Picking a set drops its links into the box below and fetches data right away. "Save current" stores whatever is in the box under a name you choose.

YouTube videos & Shorts: stats fetched via API. TikTok, Bilibili, Ruliweb, VM and others: content type detected, stats shown as — (APIs not publicly available).

💡 Click a column header to sort — first click ascending (▲), second descending (▼), third clears back to original order. Blank values always sort to the bottom. Then "Copy table" and paste into Excel (Ctrl+V) — rows copy in the order shown.
